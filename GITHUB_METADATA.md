# GitHub repository metadata

GitHub pin cards use **Description** and **Topics** from **Settings → General** (not from files). Apply these there so your profile pins stay readable.

|--------|--------|
| **Description** | Lightweight Intelligent System Assistant prototype: Python + Eel desktop shell, speech-driven commands, app/web shortcuts; falls back to a local Llama model via Ollama when commands do not match. |
